# River Duel 프로젝트 개요

## 1. 프로젝트 목적
개인 프로젝트를 통해 게임 개발의 기획, 설계, 구현, 테스트,
배포까지 전체 개발 과정을 직접 수행하는 것을 목적으로 한다.

과거에 즐겼던 2D 스킬 대전 게임의 핵심 재미인
'논타겟 스킬의 적중과 회피'를 현대적인 방식으로 재구성한다.

## 2. 장르
2D 1:1 스킬 대전 액션 게임

## 3. 플랫폼
Windows PC

## 4. 개발 환경
- Godot 4.7.2
- GDScript
- Git / GitHub

## 5. 핵심 게임 방식
- 맵 중앙에 강이 존재한다.
- 플레이어와 상대는 서로 반대 진영에 배치된다.
- 각 캐릭터는 자신의 진영 안에서 이동한다.
- 논타겟 스킬을 발사하여 상대를 공격한다.
- 상대 공격을 직접 이동으로 회피한다.
- 상대 HP를 먼저 0으로 만들면 승리한다.

## 6. 1차 개발 목표
- 플레이어 이동
- AI 이동
- 진영 이동 제한
- 마우스 방향 조준
- 기본 공격
- 일반 스킬 3개
- 궁극기 1개
- HP 시스템
- 피해 판정
- 쿨타임 시스템
- 승패 판정
- 재시작
- Windows 실행 파일 제작

## 7. 제외 범위
1차 버전에서는 아래 기능을 구현하지 않는다.
- 회원가입
- 로그인
- 랭킹
- 상점
- 스킨
- 온라인 멀티플레이

## 8. 캐릭터 방향
개발 초기에는 특정 영웅의 역할과 스킬 구조를 참고할 수 있으나,
최종 공개 포트폴리오 버전에서는 이름, 외형, 아이콘, 음성 등
저작권이 있는 원본 에셋을 사용하지 않고 오리지널 캐릭터로 구성한다.

## 9. 완료 기준
- 게임 시작부터 승패 판정까지 한 판을 정상적으로 플레이할 수 있다.
- 플레이어와 AI 모두 공격 및 피격이 정상 작동한다.
- 각 스킬의 쿨타임이 정상 작동한다.
- 치명적인 진행 불가 버그가 없다.
- 다른 Windows PC에서 실행 가능한 빌드를 생성한다.

# v0.5 테스트 항목

| ID | 테스트 | 기대 결과 |
|---|---|---|
| UI-01 | 캐릭터 카드 클릭 | 선택 테두리가 해당 카드로 이동 |
| UI-02 | 전투 시작 | 선택한 캐릭터로 전투 시작 |
| UI-03 | Q/E/Shift/R | 서로 다른 아이콘 표시 |
| UI-04 | 스킬 사용 | 슬롯에 쿨타임 숫자 표시 |
| ULT-01 | R 사용 | 화면 중앙에 궁극기 배너 표시 |
| ARIA-01 | Q | 가속하는 관통 마력탄 |
| ARIA-02 | E | 두 발이 서로 반대 방향으로 곡선 이동 |
| ARIA-03 | Shift | 긴 순간이동 + 짧은 피해 무시 |
| ARIA-04 | R | 이동하며 크기가 커지는 대형 관통탄 |
| LYRA-01 | Q | 매우 빠른 장거리 강화 화살 |
| LYRA-02 | E | 5방향 부채꼴 |
| LYRA-03 | R | 적 진영 위에서 9발 화살비 발생 |
| SERA-01 | Q | 짧은 사거리 대형 검기 |
| SERA-02 | E | X 형태 곡선 검기 |
| SERA-03 | Shift | 긴 이동 + 검기 생성 |
| SERA-04 | R | 7개의 가속 검기 |
| CLEAN-01 | 결과→메인 | 캐릭터/투사체가 메인에 남지 않음 |

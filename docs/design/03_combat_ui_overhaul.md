# v0.5 전투/UI 개선 설계

## 목적
기존에는 캐릭터마다 투사체 색상 차이가 중심이어서 실제 플레이 체감이 유사했다.
v0.5에서는 궤적, 사거리, 속도, 공격 방식, 이동기, 궁극기 구조까지 캐릭터별로 분리한다.

## UI 검증
- 캐릭터 선택 화면에서 3명의 플레이 스타일을 한눈에 비교할 수 있어야 함.
- 선택한 캐릭터 카드가 테두리로 명확히 표시되어야 함.
- Q/E/Shift/R 아이콘은 캐릭터마다 다른 문양이어야 함.
- 쿨타임 중에는 남은 시간이 슬롯 위에 표시되어야 함.
- 궁극기 사용 시 일반 스킬보다 강한 화면 피드백이 있어야 함.

## 전투 검증
- ARIA E는 직선이 아니라 곡선으로 움직여야 함.
- LYRA E는 5방향으로 퍼져야 함.
- LYRA R은 플레이어 위치에서 발사되는 일반 투사체가 아니라 상단에서 화살비가 내려와야 함.
- SERA Q는 다른 캐릭터보다 사거리가 짧고 크기가 커야 함.
- SERA Shift는 장거리 이동과 동시에 검기를 생성해야 함.
- ARIA R은 이동 중 크기가 증가하고 관통해야 함.

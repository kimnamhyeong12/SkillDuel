# 게임 플로우 설계

1. Main Menu
   - 게임 시작
   - 누적 전적
   - 게임 종료

2. Difficulty Select
   - 초급
   - 중급
   - 상급

3. Character Select
   - ARIA
   - LYRA
   - SERA

4. Battle
   - 플레이어 선택 캐릭터
   - AI는 나머지 캐릭터 중 하나 선택
   - 난이도에 따라 AI 파라미터 변경

5. Result
   - Victory / Defeat
   - 누적 승/패/승률
   - 다시 대전
   - 메인 화면

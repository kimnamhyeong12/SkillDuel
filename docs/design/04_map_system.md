# 맵 시스템 설계 v0.6

## 목적
맵을 단순 배경이 아니라 전투 의사결정에 영향을 주는 게임 요소로 사용한다.

## 흐름
캐릭터 선택 이후 맵 선택 화면을 거쳐 전투를 시작한다.

## 맵별 기믹
- Arcane River: 기믹 없음
- Rain Ruins: Puddle 진입 시 이동속도 ×0.55
- Scorched Gorge: Heat Zone 진입 시 0.5초마다 4 HP 감소

## 설계 원칙
- 효과는 Player와 CPU 모두 동일하게 적용
- 기믹 영역은 시각적으로 구분 가능
- HUD에 현재 지형 디버프를 표시
- 향후 맵 추가 시 `selected_map` 분기와 지형 영역 배열만 확장할 수 있도록 구성

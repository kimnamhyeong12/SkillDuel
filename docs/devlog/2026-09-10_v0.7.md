# 2026-09-10 개발 기록 - v0.7

## 목표
캐릭터의 역할 차이를 더 분명하게 만들고, 중앙 강 자체에도 전투 목적을 추가한다.

## 변경
- SERA E를 X 검기에서 투사체 튕겨내기로 변경
- 반사 투사체 피해량 보너스 추가
- CPU SERA도 튕겨내기 사용
- Scorched Gorge 삭제
- Frozen Pass 설원 맵 및 빙판 미끄러짐 추가
- 중앙 강 Heal Pack 시스템 추가
- 약 10초마다 좌/우에서 번갈아 등장
- 먼저 공격한 진영 HP 35 회복
- HUD에 힐팩 타이머/획득 표시

## 플레이 의미
중앙 강은 단순한 이동 제한선이 아니라 주기적으로 회복 자원이 지나가는 경쟁 공간이 된다.
플레이어는 상대 공격 회피와 동시에 힐팩 타이밍에 맞춰 사격할지 판단해야 한다.

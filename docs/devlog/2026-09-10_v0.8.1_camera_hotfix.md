# v0.8.1 Camera Hotfix

## 문제
일부 기존 프로젝트에 `Camera2D` 노드가 반영되지 않은 상태에서
`camera.offset`을 사용하면서 null instance 오류가 발생했다.

## 수정
- `main.gd`가 시작 시 Camera2D를 탐색
- 없으면 런타임에 Camera2D 자동 생성
- camera 사용 전 `is_instance_valid()` 검사
- 메인/선택 화면 복귀 시 shake offset 초기화

## 결과
`Invalid assignment of property or key 'offset' ... null instance` 오류를 방지한다.

# 2026-09-09 개발 기록 - v0.4

## 목표
단순 전투 프로토타입을 '게임처럼 처음부터 끝까지 플레이 가능한 구조'로 확장한다.

## 구현
- 메인 화면
- 난이도 선택
- 캐릭터 선택
- AI 난이도 파라미터 적용
- 오리지널 캐릭터 3종 프로토타입
- 캐릭터별 스킬 패턴 및 시각 효과 분리
- 스타일이 개선된 강/잔디 전장
- 결과 화면
- 누적 승/패/승률 저장

## 설계 이유
전투 기능만 존재하는 프로토타입보다 사용자 흐름 전체를 구현하여 실제 완성형 게임의 구조를 먼저 고정한다.
그래픽은 추후 교체 가능하도록 전투 로직과 분리된 상태를 유지한다.

- 피격/스킬 애니메이션 강화
- 캐릭터 선택 화면 초상화 고도화
- 사운드/BGM
- AI 회피 패턴 및 캐릭터별 AI 스킬 사용

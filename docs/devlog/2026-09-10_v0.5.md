# 2026-09-10 개발 기록 - v0.5

## 목표
UI와 캐릭터별 스킬의 체감 차이를 크게 개선한다.

## 문제
기존 버전은 색상과 발사 개수만 달라 실제 전투에서 캐릭터 차이가 약했다.

## 개선
- 캐릭터별 스킬 아이콘 추가
- 캐릭터 선택 UI 개선
- 투사체 trajectory 시스템 추가
- 직선 / 곡선 / 가속 / 관통 / 성장 효과 구현
- 세 캐릭터의 Q/E/Shift/R 메커니즘 분리
- 궁극기 전용 화면 배너 추가
- AI도 캐릭터별 특수 공격 사용
- 메인화면 복귀 시 전투 오브젝트 정리 유지

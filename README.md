# River Duel

개인 포트폴리오용 2D 1:1 스킬 대전 게임 프로젝트.

## 프로젝트 목표
강을 사이에 둔 두 캐릭터가 각자의 진영 안에서 이동하며
논타겟 스킬을 피하고 맞히는 전투 게임을 구현한다.

## 개발 환경
- Godot 4.7.2
- GDScript
- Windows PC
- Git / GitHub

## 1차 완성 범위
- 플레이어 이동

- 마우스 방향 조준
- 기본 투사체
- HP / 피해 처리
- 스킬 4종
- 쿨타임
- AI 상대
- 승패 처리
- 재시작
- Windows 빌드

# SkillDuel v0.4 - Arcade Flow Prototype

Godot 4.7.2 / GDScript 기반 개인 포트폴리오용 2D 스킬 대전 게임.

## 현재 게임 흐름

F5
→ 메인 화면
→ 게임 시작
→ 난이도 선택(초급 / 중급 / 상급)
→ 캐릭터 선택
→ AI 캐릭터 자동 결정
→ 1:1 대전
→ 승리/패배 결과 화면
→ 누적 전적(승/패/승률) 표시
→ 다시 대전 또는 메인 화면

## 캐릭터

### ARIA
마법사형. 마법탄, 3연발, 순간이동, 대형 마력 폭발.

### LYRA
궁수형. 화살, 5연사, 구르기, 초대형 관통 화살.

### SERA
검사형. 검기, 쌍검기, 장거리 돌진, 연속 궁극 검기.

캐릭터와 스킬은 외부 게임 IP를 사용하지 않은 오리지널 프로토타입입니다.

## 난이도 차이

- 초급: 느린 AI 이동, 긴 공격 간격, 낮은 명중률/피해
- 중급: 기본 밸런스
- 상급: 빠른 AI 이동, 짧은 공격 간격, 높은 명중률/피해

## 조작

- WASD: 이동
- 마우스: 조준
- LMB: 기본 공격
- Q / E: 스킬
- Shift: 이동기
- R: 궁극기
- ESC: 난이도/캐릭터 선택 화면에서 뒤로

## 전적

승/패는 `user://skillduel_stats.cfg`에 저장되어 게임을 다시 실행해도 유지됩니다.
